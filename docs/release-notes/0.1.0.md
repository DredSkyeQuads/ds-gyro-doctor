# Gyro Doctor v0.1.0 - October 2026

Version 0.1.0 is the first release of Gyro Doctor. Please report any issues via the DredSkye Discord.

## What is new

This is the first public beta release of Gyro Doctor, a software utility that
repairs the data track of a DJI O4 video that exhibits incorrect motion when
stabilized by Gyroflow.

Version 0.1.0 has three commands:

- `gyro-doctor` repairs the gyro data track of a DJI O4 video and saves the
  repaired video alongside the original.

- `gyro-doctor-chart` draws a chart of the camera movement recorded in the gyro
  data track of a DJI O4 video. Use it to inspect the gyro data and noise events
  found in the video, and to compare the original gyro data with the repaired
  gyro data. You must run `gyro-doctor` on the video first to see the detection
  results.

- `gyro-doctor-render` runs Gyroflow, installed separately, to render a side by
  side video of either (a) the original video without stabilization against the
  unrepaired video stabilized by Gyroflow, or (b) the video stabilized by
  Gyroflow before and after the gyro data repair. You must run `gyro-doctor` on
  the video first in order to render the repair.

Gyro Doctor is released under the GPLv3 license, and can be built from source at
https://github.com/DredSkyeQuads/ds-gyro-doctor.

Binary distributions are provided for the following architectures:

- Windows x64,
- macOS on Apple Silicon,
- macOS on Intel, and
- Linux x64.

*Note: This product does not bundle Gyroflow.

## Known limitations

### Horizon lock is unusable on a repaired video

A repair leaves an offset in the absolute orientation of every later part of the
gyro data track, which makes horizon lock in Gyroflow unusable on a repaired
video. Stabilize a repaired video with horizon lock off.

### The executables are unsigned

On the first run of an executable, Windows SmartScreen or macOS can block it,
and an antivirus program can flag it. Allow the executable in the warning that
the system or the antivirus program shows.

### False Positives

Some flight characteristics can trigger false positives in `gyro-doctor`. In many
cases a false positive falls near the noise floor, so its repair is minimal and
does not impact Gyroflow stabilization. Use the "do not repair" option to exclude
false positives if necessary.

### Gyro Doctor cannot render some video paths

`gyro-doctor-render` stops with an error on a video whose path holds `#` or is on
a mapped network drive.
